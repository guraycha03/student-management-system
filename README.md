# 🧑‍🎓 Student Management System (PHP + MySQL)

A beginner-friendly web-based Student Management System built using PHP, MySQL (MariaDB), and basic CSS. This project allows users to add, edit, view, and delete student records from a database.

## 🔧 Features

- Add new student details
- List all students in a responsive table
- Edit existing student records
- Delete student records with confirmation
- Basic form validation and PDO-based database operations
- Styled interface with simple and clean CSS


## 📁 Project Structure

├── add_student.php # Form to add a student
├── config.php # Database connection using PDO
├── delete_student.php # Deletes a student
├── edit_student.php # Edit student details
├── list_students.php # List all students
├── style.css # Stylesheet
└── student.sql # Database schema (exported from phpMyAdmin)
